# Sistema de Empréstimo de Livros

Projeto acadêmico de sistema de gestão de empréstimos de livros, aplicando os padrões de projeto MVC, DAO, Builder, Command, Factory Method e Polimorfismo (via Interface).

### Stack

- Back-end: Node.js + Express + TypeScript
- Front-end: React + TypeScript (Vite) + Tailwind
- Banco de dados: SQLite (better-sqlite3)
- Gerenciador de pacotes: pnpm
